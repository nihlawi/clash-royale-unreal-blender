# Unreal build guide for the Clash Royale-style prototype

## Required software
- Unreal Engine 5.3 or newer
- Visual Studio 2022 with C++ desktop development
- Blender 4.x for procedural mesh generation
- Python 3.10+ for SFX generation

## Setup
1. Open the `ClashRoyaleRTS.uproject` file.
2. Let Unreal generate project files when prompted.
3. Open the project solution in Visual Studio.
4. Build the project in Development Editor configuration.
5. If the C++ compile fails, make sure the engine version matches the project file.

## In-editor assembly steps
1. Create a new `GameplayMap`.
2. Add `AClashRoyaleRTSGameModeBase` to the world.
3. Add `AArenaBuilder` and place it at origin.
4. Add `ARTSPlayerController` to the Player Start flow.
5. Add `AEnemyWaveManager` to the level and assign spawn points.
6. Add a `UCombatHUDWidget` to the viewport and bind the HUD values to the game state.
7. Add the towers and spawn points from the arena builder.
8. Assign the deck cards using `URTSCardBlueprintLibrary` or `FDeckCard` data assets.
9. Import low-poly models generated by the Blender script into your `Content/Art` folder.
10. Test the match loop: elixir, deploy, combat, towers, timer, win states.

## Common build issues
- Missing engine version: confirm UE 5.3 in `.uproject`
- Module compile issues: regenerate project files after adding new C++ classes
- Asset import failures: ensure generated `.glb` files are placed in `Content/Art`
- Gameplay not spawning: check actor tags and world references for towers and spawners
